## Classification key

- A: real project image used directly
- B: existing image retained as a crop alternative
- C: missing asset requiring generation
- D: UI/brand asset
- E: video media or thumbnail source

The two class C assets were generated to cover approved-story subjects absent from the project library: school field sports and clean-water hygiene.
